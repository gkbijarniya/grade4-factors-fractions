# Factor & Fraction Fun

A Grade 4 Maths practice website covering **Factors** and **Fractions**.

## What's included
- Simple explanations and examples
- Factor pairs and common factors
- Fraction types, equivalent fractions, and comparison
- Interactive 25-question quiz
- Instant feedback and final score
- Mobile-friendly, single-file website
